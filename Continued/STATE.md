# Состояние проекта (обновлено 2026-11-01, после коммита 5a62c18)

## Что за проект
**«Уралия: Дыхание Предков»** (URALIA) — мобильная коллекционная AFK-RPG для Android на мотивах башкирского эпоса
и Южного Урала. Герои, кампания по главам-регионам, автобои, арена, гильдии, рейды, события, караван, сюжет с выборами.

- **Репозиторий:** `maillunex-lang/UfaArena`. Ветка разработки: `ccr-39bc6428-16s1r4`. Ветка `apk` — только файл APK
  (`https://github.com/maillunex-lang/UfaArena/raw/apk/uralia-latest.apk`).
- **Клиент:** Godot 4.5.1 (`client/`), Android arm64, версия **0.7.7 (versionCode 19)** — последний собранный APK (меню из редактора интерфейса).
- **Сервер:** FastAPI + PostgreSQL 16 + Redis (`server/`), модульный монолит, Alembic (голова миграций **0015**).
- **Прод:** VPS 144.31.254.99 (1 vCPU, 2 ГБ, общий с другими проектами), `docker compose` в `/opt/uralia`,
  сервисы `api`, `db`, `redis`, `ai-director`. Админка: `http://144.31.254.99:8000/admin` (токен из `.env`).

## Living World AI — что уже есть (мастер-ТЗ: `docs/URALIA_AI_MASTER_SPEC.md`)
- **Фаза 1** — аудит кода и VPS. **Фаза 2** — AI Director (отдельный процесс `python -m app.ai`, сервис `ai-director`),
  очередь задач с идемпотентностью, расписания, реестр 500 ИИ, сон без живых игроков, защита от перегрузки хоста.
- **Фаза 3** — личности (8 черт, амбиции, привычки, эволюция), слои силы, речь (манера, эмоции, контекст),
  поставщики языковой модели (локальная/Groq/Google/OpenRouter/Cloudflare/HF, выключено по умолчанию), память
  (архив, биография, контрольные точки, перенос).
- **Фаза 4** — отношения и группы, каналы чата (регион/событие/союз/круг/объявления), союзы гильдий (игровая функция),
  выборы и дипломатия ИИ-гильдий, общение ИИ с игроками с лимитами и отказом.
- **Фаза 5** — ИИ играют **по правилам игры** через те же функции API (ключи повтора), PvP (анализ соперника,
  лимиты), экономика по правилам (без VIP, без «виртуальной» казны), вклад в события отдельной строкой ≤ 20%.
- Чат ИИ: не чаще 1 сообщения в 10 с на канал, тишина 5–15 мин после обсуждения.
- Админка → «ИИ-жители»: 15 разделов (Director, персонажи с карточкой, характеры, речь, память, отношения,
  гильдии ИИ, общение с игроками, каналы, игра и экономика, расписания, очередь, журнал).
- Решения: `docs/URALIA_AI_DECISIONS.md` (A-01…A-11, D-01…D-12, D-09a, P3-01…P5-07).
