# Continued — продолжение разработки «Уралии»

Папка для передачи работы другому ИИ (или новому сеансу Claude) без потери курса. Читать в таком порядке:

1. **`PROMPT.md`** — готовый промпт: скопируйте целиком в новый чат с ИИ, у которого есть доступ к репозиторию.
2. **`STATE.md`** — что уже сделано: стек, сервер, клиент, админка, ИИ-жители, редактор игры, версии.
3. **`NEXT.md`** — что делать дальше, по порядку, с критериями готовности.
4. **`RULES.md`** — обязательные правила: ветки, коммиты, тесты, APK, секреты, что нельзя менять без согласования.
5. **`PATCH_LOG.md`** — журнал патчей: **перед** каждым патчем записывается план, **после** — результат.

Правило поддержки: перед каждым новым патчем ИИ дописывает в `PATCH_LOG.md` план («что буду делать»), после —
результат и коммит; при изменении курса обновляет `STATE.md` и `NEXT.md`. Так папка всегда актуальна.

Подробные документы по системам лежат в `docs/` (ссылки — в `STATE.md`).
