# Отчёт: блок 0–1 — аудит среды и первый вертикальный срез

## Что сделано
1. **Аудит среды и репозитория** — [`docs/AUDIT.md`](../AUDIT.md). Репозиторий был пустым. Установлены Godot 4.5.1, шаблоны экспорта, Android SDK 35 и Python-окружение; поднят локальный PostgreSQL 16.
2. **Сервер (FastAPI, модульный монолит)**
   - Схема из 34 таблиц по blueprint: все таблицы MVP, плюс таблицы под будущие блоки (guilds, ai_*, admin_actions) и `idempotency_keys`. Начальная миграция Alembic применена к PostgreSQL; `alembic check` расхождений со схемой не находит.
   - Авторизация: гостевой вход, короткий JWT (15 мин), opaque refresh-токены (в БД хранится только SHA-256), ротация, отзыв всей семьи токенов при повторном использовании старого refresh. Привязка email/пароля (scrypt), вход, выход.
   - Весь API-baseline из TDD плюс вспомогательные эндпоинты (`/campaign`, `/summon/pools`, `/rewards/afk`, `/player/onboarding|nickname|settings`, уровень героя, `/content/public-key`, пакет `core.balance`).
   - Детерминированная серверная симуляция боя: клиент получает лог событий и только визуализирует его, подделать победу нельзя.
   - Экономика: ledger, атомарные списания, идемпотентность, защита от гонок (блокировки строк в PostgreSQL), AFK по серверному времени с лимитом от Хранилища, призыв с открытыми шансами и гарантией, дубликаты превращаются в осколки и звёзды.
   - Крепость (6 зданий с эффектами, Дом гильдий закрыт до блока гильдий), цепочка заданий + ежедневные + побочное, почта с вложениями.
   - Uralia Update System, первый срез: RSA-SHA256-подписанный манифест (каналы, minimum_client_version, kill switch, SHA-256, размер, URL, зависимости), загрузка пакета данных, `verify-install`.
   - Rate limit (Redis или память), аудит-лог, health live/ready, заголовки безопасности. Секреты только в env; для beta/prod без `URALIA_JWT_SECRET` сервер не стартует.
3. **Клиент Godot 4.5 (Android, портрет 9:16, Mobile renderer)**
   - Слои: autoload (network / state / audio / graphics / models / routing), world, screens, UI-кит, content-loader.
   - **Крепость хранителей**: 3D-диорама на гексагональном острове в водах Агидели, за рекой Уральский хребет, в центре выбранный герой (листается). Контекстные кнопки, AFK-сундук «Дозор» с таймером по серверному времени, кнопка «В бой».
   - **Кампания**: 3D-карта «Шиханы Приагиделья» — река, Стерлитамак, шиханы Юрактау, Куштау, Шахтау (карьер), Торатау, маршрут, статусы узлов, касание по узлу открывает карточку с врагами и наградами.
   - **Бой**: изометрическая 3D-арена с тематикой по типу территории (природа, поселения, подземелья с факелами, разломы, измерение босса). Анимированные модели, рывок в ближнем бою, снаряды, ударные волны умений, лечение, щиты, оглушение, всплывающий урон с критами, HP- и энерго-бары (billboard-шейдер), баннер умения, тряска камеры, скорость x1–x3, пропуск, экран итогов с наградами от сервера.
   - **Герои**: коллекция с 2D-портретами, отрендеренными из 3D-моделей; карточка героя со статами, умением и лором; повышение уровня.
   - **Формация** (2+3), **призыв** с анимацией раскрытия, **здания**, **задания**, **почта**, **режимы** (поэтапный релиз), **профиль и настройки**: адаптивная графика Авто/Низкая/Средняя/Высокая, громкость, адрес сервера, привязка email, выход.
   - **Онбординг**: сюжетный диалог с портретами → бой 1-1 → почта → призыв → формация → AFK. Шаг хранится на сервере; подсказка показывается на главном экране, нужная кнопка навигации пульсирует.
   - **Потеря сети**: ретраи с экспоненциальной задержкой и тем же `Idempotency-Key`, баннер «Нет связи» с кнопкой «Повторить», повтор получения награды после боя.
   - **Liquid Glass UI**: шейдер стекла (размытый фон + оттенок + блик); на низком уровне графики размытие отключается.
4. **Ассеты** — реально скачаны, проверены и встроены в сцены (подробно в `ASSET_REGISTER.csv`, подтверждения лицензий в `licenses/`): KayKit Adventurers / Skeletons / Medieval Hexagon / Dungeon Remastered (CC0), HDRI Poly Haven (CC0), RPG Sound Pack (CC0), шрифт Philosopher (OFL). Музыка написана для проекта: процедурная генерация по мотивам тембра курая с бурдоном. Иконки валют и навигации нарисованы кодом.
5. **APK**: `build/uralia-debug.apk` — debug-сборка, подписана debug-ключом, arm64-v8a + armeabi-v7a + x86_64, targetSdk 35, разрешения INTERNET и ACCESS_NETWORK_STATE. В git не коммитится (108 МБ).

## Реально запущенные команды (основные)
- `godot --headless --import`, `godot --path client res://tools/Check.tscn` — проверка компиляции всех скриптов: `broken=0`.
- `pytest -q` на SQLite: **11 passed, 2 skipped** (тесты гонок нужны только для PostgreSQL); на PostgreSQL 16: **13 passed**.
- `alembic upgrade head` и `alembic check` на PostgreSQL: «No new upgrade operations detected».
- `server/scripts/verify_backup_restore.sh`: **BACKUP_RESTORE_OK** (совпали число строк и суммы кошельков, ledger сходится).
- E2E-прогон клиента против живого сервера (Xvfb, `URALIA_E2E`): весь цикл нажатием реальных кнопок. Результаты:
  `RESTART cleared_before=["1-1"] cleared_after=["1-1"] gold_before=2975 gold_after=2975 -> OK`,
  `OFFLINE banner=true`, `RECOVERED offline=false`, `E2E_DONE`. В логе сервера только два не-2xx ответа: ожидаемые 409 «AFK ещё копится».
- `godot --headless --export-debug "Android"` → APK. `apksigner verify` и `aapt2 dump badging` проверены.

## Тесты сервера
Полный MVP-цикл (гость → бой → награда → повтор с тем же ключом без двойной выдачи → почта → призыв → задание → AFK → крепость → уровень → refresh = «перезапуск» с тем же прогрессом), повторное использование refresh-токена, чужие герои и закрытые узлы, нехватка средств, конфликт идемпотентности, авторизация, привязка и вход, подпись и хеш манифеста, rate limit, детерминизм боя, сверка ledger, параллельные запросы: 8 одновременных `complete` и 6 одновременных `afk/claim` выдают награду ровно один раз.

## Ограничения (честно)
- APK **не запускался на реальном Android-устройстве или эмуляторе** (их нет в среде). Не проверены FPS, нагрев и память на слабых устройствах. Скриншоты сняты через программный OpenGL-рендер.
- Godot ходит в сеть нативными сокетами, а не через Java-стек, поэтому HTTP на dev-сервер должен работать и на Android 9+. Это не проверено на устройстве. Для беты обязателен HTTPS.
- Docker-стек описан, но не поднимался (нет демона). Redis-лимитер написан, тесты шли на in-memory варианте.
- Update System: есть только манифест, подпись, загрузка пакета данных, атомарная запись и откат версии в клиенте. Не сделаны админ-публикация, resume-загрузка больших пакетов, проверка свободного места и загрузка Godot resource pack — это блок «Update System».
- Публичный ключ манифеста в dev-канале запрашивается при первом запуске (TOFU). Для beta/stable ключ должен быть зашит в `client/config/content_public_key.pem`.
- Герои — 10 вариаций на 5 ригах KayKit (разные аксессуары, оружие, тонировка, свечение). Для «премиальной» графики позже нужны уникальные модели и лица, а также кастомные VFX-текстуры. Ассеты Kenney недоступны через прокси.
- Временные правила для нерасшифрованных букв GDD перечислены в [`GDD_OPEN_QUESTIONS.md`](../GDD_OPEN_QUESTIONS.md).

## Риски
- Культурная корректность образов эпоса и башкирских мотивов: нужна консультация перед бетой.
- Баланс черновой: экономика под LiveOps потребует телеметрии.
- Размер APK (108 МБ) в основном даёт движок под 3 ABI. Для релиза нужен AAB со split по ABI.

## Ручная проверка
1. `cd server && .venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000`.
2. Установить `build/uralia-debug.apk` на эмулятор (сервер доступен как `10.0.2.2:8000`) или на устройство: в «Профиле» указать `http://<IP_ПК>:8000`.
3. Пройти онбординг: диалог → Кампания → «Сражаться» → Почта → Призыв ×1 → Герои → Формация → «Дозор».
4. Закрыть и снова открыть приложение: прогресс, валюты и пройденные узлы должны сохраниться.
5. Выключить сеть: должен появиться баннер «Нет связи», после «Повторить» — восстановление.
