# Промпт: анализ и настройка баланса героев «Уралии»

Используйте, когда герои созданы и отредактированы в админке («Редактор игры»). Самый простой путь: админка →
«Редактор игры» → «Баланс» → «📋 Скопировать отчёт и задание для анализа» и вставить в чат с Claude. Либо отправьте
этот текст целиком:

---

Проанализируй баланс героев игры «Уралия» (репозиторий maillunex-lang/UfaArena, ветка разработки) и настрой его.

**Цели**
1. Ни один герой не убивает среднего героя своего уровня с одного удара, даже критом (в отчёте: «% здоровья среднего
   героя» < 100%, лучше < 60% для обычных умений).
2. Внутри одной редкости — сопоставимая сила (отклонение силы не больше ±2σ), разные роли (танк, урон, лекарь,
   поддержка, контроль).
3. Более высокая редкость сильнее, но не «ломает» игру: в дуэлях 1×1 никто не выигрывает больше ~75%, кроме
   мифических против обычных.
4. Кампания проходима: стартовые герои проходят первые главы, боссы не убивают отряд за один удар.

**Как работать**
1. Получи отчёты: `GET /admin/api/game/balance?level=10&duels=1`, `level=40`, `level=80` (или попроси меня прислать
   их из админки) и список героев `GET /admin/api/game/heroes?enemies=1`.
2. Для каждого проблемного героя назови причину: база (здоровье/атака/защита/скорость), рост за уровень, множитель
   умения/ульты, число ударов, крит и урон крита, механика набора умений.
3. Предложи конкретные новые значения и примени их через админку («Редактор игры» → «Герои») или
   `PUT /admin/api/game/heroes/{code}` (правки хранятся слоем поверх кода, с историей и откатом).
4. Перепроверь отчёты после правок на уровнях 10, 40, 80; проверь прохождение кампании (боссы глав) симуляцией.
5. Кратко опиши изменения и ожидаемый эффект; запиши их в `docs/` (журнал баланса).

**Ограничения**
- Прогресс игроков (уровни, звёзды, коллекции) не трогаем.
- Героев, которых уже получили игроки, ослабляем мягко (−10…−20% за шаг), не отключаем без согласования.
- Правила боя (формула урона, движок) не меняем без согласования — только данные героев.
- Изменения — только через слой правок админки (без правки `app/game/data.py`), чтобы их можно было откатить.
