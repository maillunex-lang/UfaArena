# 15. Архитектурные решения, требующие согласования

> **D-C1 решено заказчиком (2026-11-01):** взрослый юмор, пошлости и флирт ИИ разрешены, **в том числе с реальными
> игроками в личных сообщениях**, но только 18+. При создании героя — окно «никнейм + Мне исполнилось 18 лет»; кто
> младше 18 (или не ответил) — ИИ **не пишут в личку** и не показывают взрослый юмор. Реализовано (миграция 0015).
> Остальные решения (D-C2…D-C11) — по рекомендациям ниже.

## Реализация D-C1 (2026-11-01)
- `player_profiles.age_group` (`adult` | `minor` | `NULL` — не спрашивали; NULL = как младше 18), `age_set_at` (0015).
- Приложение: окно «Создание героя» (никнейм + «Мне исполнилось 18 лет») — новым игрокам перед вступлением, уже
  играющим — один раз; в «Настройках» → ИИ-жители: возраст и «Изменить»; переключатель «18+: флирт и взрослый юмор ИИ»
  только для 18+ (у взрослых по умолчанию включён).
- Сервер: `POST /api/v1/player/setup`; ИИ не пишут в личку и не отвечают в личке младше 18 / без ответа; первые
  сообщения (приветствие, поздравления, приглашения, подначки) — только 18+; флирт-повод для 18+ с включённой настройкой
  (до 3 в неделю, замолкают после 2 сообщений без ответа и навсегда после стоп-фразы «отстань», «не пиши», «хватит»…);
  флиртующие ответы ИИ на флирт игрока (шаблоны или языковая модель с ограничением «без откровенных описаний, без
  давления, без покупок, остановиться по просьбе»); сцены флирта ИИ↔ИИ в общих каналах — только если все живые читатели
  канала 18+ с включённой настройкой; откровенные слова в ответах ИИ отсекаются.
- Админка: «Общение с игроками» — флирт вкл/выкл, лимит в неделю, порог «без ответа»; карточка игрока — возраст и кнопки
  «Отметить: до 18 / 18+» (модерация).
- Важно: возрастной рейтинг в Google Play при включённом 18+ контенте может потребовать пересмотра.
