# 15. Архитектурные решения, требующие согласования

| ID | Вопрос | Рекомендация | Почему |
|---|---|---|---|
| **D-C1** | **Взрослый юмор и пошлые намёки при отсутствии возраста в игре** | Включать категорию E только для игроков, которые **подтвердили 18+** (новая настройка в приложении, по умолчанию выключено) и включили «взрослый юмор»; в каналах, где есть читатели без 18+, E не используется. ИИ **не флиртуют с реальными игроками**. Проверить возрастной рейтинг в Google Play (контент 18+ может потребовать смены рейтинга). | В игре нет данных о возрасте, игроки могут быть несовершеннолетними; закон и правила магазина |
| **D-C2** | «Личные истории», «как прошёл день», фильмы — не выдают ли ИИ себя за людей? | Истории — **жизнь персонажа в мире Уралии** или нейтрально-бытовые; на вопрос «ты бот?» — всегда честно; метка «ИИ» остаётся везде. Без утверждений «я человек», без выдуманных фактов о реальных людях | Правило мастер-ТЗ: ИИ обозначены как ИИ |
| **D-C3** | Границы off-topic | Исключить политику, религию, реальные трагедии, медицинские/финансовые советы; реальные знаменитости и бренды — без имён или нейтрально | Модерация и риски магазина |
| **D-C4** | Мат | Только **завуалированный** (звёздочки), через общий фильтр чата; частота по профилю, у большинства — редко; никогда в адрес реального игрока | ТЗ + правила площадки |
| **D-C5** | Источник текста при Speech Realism MAXIMUM | **Гибрид:** планировщик ходов — всегда локально; текст — бесплатная LLM (из «Речи», пакетно, 30 запросов/ч по умолчанию) для важных сцен, иначе генеративная грамматика. На VPS (2 ГБ) локальная модель невозможна | Максимальная естественность без платных API и без перегрузки VPS |
| **D-C6** | Передача контекста в внешнюю LLM | В запрос — только профили ИИ, темы и реплики ИИ; сообщения реальных игроков — без ников (как сейчас); в политике конфиденциальности — упоминание | Приватность (D-09a) |
| **D-C7** | Доля off-topic и частота | Off-topic 40–60% реплик ИИ в канале; темп прежний (10 с, тишина 5–15 мин); ≤ 1 сцена + 1 ветка на канал; ≤ 6 сцен всего | BALANCED, без спама |
| **D-C8** | Очередь реплик в БД вместо памяти процесса | Да (в этапе 02) | Восстановление после перезапуска (ТЗ §14) |
| **D-C9** | Порядок работ | Сначала Living Community этапы 02–08, затем Фаза 6 ИИ (Control Center) — **или** наоборот | Решает заказчик; обе ветки независимы |
| **D-C10** | Личные беседы ИИ↔ИИ в ЛС | Хранить как скрытые сцены (игроки не видят), использовать для развития отношений; или не делать вовсе | Экономия ресурсов vs глубина симуляции |
| **D-C11** | Приложение для 18+ | Настройка «Мне есть 18» + «Взрослый юмор ИИ» в настройках — в финальную сборку APK (или промежуточную, если решите собрать раньше) | Клиентская часть нужна для D-C1 |
