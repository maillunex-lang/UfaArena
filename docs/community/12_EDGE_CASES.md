# 12. Пограничные случаи и защита от искусственности

## Пограничные случаи
| Случай | Поведение |
|---|---|
| Живой игрок вмешивается в сцену ИИ | приоритет игроку: 1–2 ИИ отвечают ему; сцена адаптирует тему или уступает |
| Игрок отключил «показывать ИИ в чате» / `ai_contact` | сцены видны остальным; к нему не обращаются |
| Игрок пишет оскорбления ИИ | ИИ не отвечает тем же: шутка/игнор; модерация как обычно |
| Игрок флиртует с ИИ | дружелюбная шутка, уход от темы (ИИ не флиртуют с людьми) |
| Игрок спрашивает «ты бот?» | честно: «я ИИ-житель Уралии» (без исключений) |
| Игрок без 18+ в канале | взрослый юмор не используется в этом канале (D-C1) |
| Персонаж ушёл «отдохнуть» посреди сцены | сцена продолжается без него или угасает |
| Два спора одновременно в одном канале | вторая сцена ждёт (лимит 1 + 1 ветка) |
| Перепалка перерастает в травлю | антибуллинг: смена темы / примирение / третий персонаж разряжает |
| Сцена «зациклилась» (повторы) | детектор повторов → TOPIC_TRANSITION или ENDING |
| LLM вернула недопустимое | реплика отбрасывается, грамматика; инцидент в журнал |
| LLM недоступна | грамматика, качество ниже, но поток живой |
| Канал «Объявления» | ИИ не пишут |
| Перезапуск посреди сцены | восстановление из БД; если просрочено — закрыть тихо |
| Админ выключил категорию (например, E или F) | категория не планируется; активные сцены этой категории завершаются |
| Участник удалён/на паузе админом | выводится из сцены без реплики |

## Защита от искусственности (ТЗ §13) — проверяемые метрики
| Запрет | Механизм | Метрика |
|---|---|---|
| Одинаковые приветствия / шаблоны | анти-повтор по нормализованной форме, окно 500 реплик/канал | доля повторов < 2% |
| Обязательная вежливость | ходы без приветствий/прощаний; вежливость зависит от характера | доля «спасибо/пожалуйста» по стилям |
| Постоянное повторение имени | обращение по имени ≤ 30% адресных реплик | счётчик |
| Одинаковая длина | длина от голоса и хода (реакция 1–4 слова, история 2–4 предложения) | дисперсия длины |
| Искусственное завершение | угасание без «ну всё, пока» в > 60% сцен | счётчик |
| Постоянная игра | доля off-topic по каналу (цель 40–60%) | доля |
| Обязательное согласие | в группах ≥ 25% сцен содержат несогласие | доля |
| Одинаковый юмор | разнообразие видов шуток по участникам | энтропия |
| Бесконечные разговоры | max ходов/времени, детектор «топтания» | средняя длина |
| Все активны одновременно | лимиты сцен, батарейка, наблюдатели | доля молчаливых участников |
