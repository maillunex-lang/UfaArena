# 10. Интеграция с памятью и отношениями

## Память (существующий `app/ai/memory.py`, без параллельной системы)
- **Краткосрочная** — `ai_scene_turns` (контекст сцены, последние 10–20 ходов), удаляется через 7 дней.
- **Долговременная** — `ai_memory`, только значимое. После сцены **Memory Extractor** оценивает кандидатов:

| Что | Вид памяти | Когда сохраняется | Важность |
|---|---|---|---|
| Факт о собеседнике (любит острое, боится высоты) | `preference` | прозвучало как личное утверждение | 1–2 |
| Обещание («завтра вместе на босса») | `promise` | явное обязательство | 2–3 |
| Личная история | `personal_story` | рассказ ≥ 2 реплик | 2 |
| Удачная шутка компании | `inside_joke` | ≥ 2 реакций/подхват | 2 |
| Конфликт / примирение | `relationship` | спор с колкостями / извинение | 2–3 |
| Новое знакомство | `relationship` | первая содержательная беседа | 1 |
| Незавершённая тема | `topic_open` | сцена прервана на вопросе | 1 (живёт 7 дней) |

Случайные реплики («ага», «лол») не сохраняются. При LLM итог сцены можно получить одним коротким запросом
«что запомнить» (опционально), иначе — правила выше. Архив/биография — как уже устроено (90 дней → архив).

## Отношения (существующий `app/ai/social.py`)
Новые события `relate()`: `scene_laugh` (+симпатия), `scene_support` (+доверие), `scene_disagree` (+соперничество
слегка), `scene_insult_soft` (± — у близких +симпатия, у чужих +неприязнь), `scene_reconcile` (−неприязнь),
`scene_ignored` (−симпатия чуть), `scene_inside_joke` (+симпатия, сохраняется шутка).
Отношения влияют обратно: выбор участников, ходы (подкол только близким), тон, взрослый юмор только при взаимной
симпатии, примирение после конфликтов. Круги друзей (группы) получают «традиции разговоров» (любимые темы круга).

## С реальными игроками
ИИ запоминают реальных игроков **только** по их сообщениям в общих каналах и личке с ИИ; приватность и отказ
(`ai_contact`) соблюдаются; в память о реальных людях не записываются личные данные (имена, адреса, телефоны —
фильтр), только игровые и нейтральные факты.
