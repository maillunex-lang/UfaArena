# 13. Тестовые сценарии

## Автотесты (сервер, при реализации)
1. **Автомат:** сцена проходит IDLE → … → COMPLETED; нелинейные переходы (кандидатов нет → IDLE; пауза → ENDING).
2. **Восстановление:** «падение» процесса посреди сцены → продолжение с того же хода, без дублей сообщений.
3. **Темп:** реплики сцены не чаще 10 с на канал, тишина после сцены 5–15 мин; лимит сцен на канал.
4. **Групповая беседа:** вопрос к залу с 6 участниками → не все отвечают, порядок не по кругу, есть адресный ответ,
   встречный вопрос, несогласие и шутка (по ходам); есть молчаливые наблюдатели.
5. **Off-topic:** при интересах «еда/кино» генерируются off-topic темы; доля off-topic в канале в пределах настройки.
6. **Юмор и мат:** персонаж с `profanity=0` не использует мат за 200 реплик; «солёный» — использует редко и только
   завуалированно; ни одна реплика не проходит `clean()` с `***`.
7. **Антибуллинг:** 3 колкости одному → смена темы/примирение.
8. **18+:** при читателе без подтверждения — ни одного хода `flirt`/E в канале; с подтверждёнными — допускается.
9. **Игрок:** прямое обращение игрока → ответ ИИ ≤ 2 реплик подряд; «ты бот?» → честный ответ.
10. **Память:** обещание и внутренняя шутка сохраняются; «ага/лол» — нет; `topic_open` возвращается callback’ом.
11. **Отношения:** смех повышает симпатию, грубость к чужому — неприязнь, примирение снижает неприязнь.
12. **Интересы:** дрейф после интересных сцен; новый лайк от близкого друга.
13. **Разнообразие:** 1000 реплик → повторы < 2%, имя ≤ 30%, длины разнообразны.
14. **LLM:** недоступна/лимит/плохой ответ → грамматика без ошибок; пакетный ответ правильно делится на ходы.
15. **Нагрузка:** 500 ИИ, 20 игроков онлайн, 6 активных сцен — такт < бюджета, память процесса в лимите 200 МБ.

## Ручная приёмка (заказчик)
Просмотр каналов в течение вечера: живость, разные характеры, off-topic, юмор и подколы, отсутствие спама,
отсутствие повторов; журнал сцен в админке.
