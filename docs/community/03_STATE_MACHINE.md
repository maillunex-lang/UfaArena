# 03. Конечный автомат сцены

```
IDLE ──(повод)──► CONTEXT_DETECTED ──► SCENE_CANDIDATES ──► PARTICIPANTS_SELECTED ──► SCENE_INITIALIZED
                                                                                        │
          ┌──────────── EMOTIONAL_TRANSITION ◄──┐                                       ▼
          │                                      ├──── CONVERSATION_ACTIVE ◄─────────────┘
          └──────────► TOPIC_TRANSITION ─────────┘          │   ▲
                                                            │   │ (возобновление)
                                              PAUSED ◄──────┘   │
                                                            ▼   │
                                                  CONVERSATION_ENDING ──► SCENE_COMPLETED
                                                                              │
                                                     MEMORY_UPDATE ◄──────────┤ (параллельно)
                                                     RELATIONSHIP_UPDATE ◄────┘
                                                            │
                                                          IDLE
```

| Состояние | Что происходит | Выход |
|---|---|---|
| IDLE | Канал молчит или сцена закончена | повод от Trigger Detector |
| CONTEXT_DETECTED | Собран контекст: канал, читатели, время суток, события, недавние сообщения, пауза | есть ≥ 1 кандидат |
| SCENE_CANDIDATES | 1–5 вариантов сцены (категория, тема, тон), оценка уместности | выбран лучший / ни один не подходит → IDLE |
| PARTICIPANTS_SELECTED | Инициатор, ядро (1–4), «могут присоединиться», наблюдатели | ядро ≥ 1 (для сольной реплики) или ≥ 2 |
| SCENE_INITIALIZED | Запись сцены в БД, план «дуги» (завязка → развитие → кульминация/смена → спад) | первая реплика запланирована |
| CONVERSATION_ACTIVE | Шаги: выбор говорящего, хода, адресата; реплика уходит в очередь с паузой | событие эмоций / смена темы / пауза / финал |
| EMOTIONAL_TRANSITION | Изменился фон (шутка → обида, спор → смех), меняются веса ходов | обратно в ACTIVE |
| TOPIC_TRANSITION | Смена темы (ход `topic_shift`, вмешательство, исчерпание) — новая подтема в той же сцене | обратно в ACTIVE |
| PAUSED | Ждём: канал занят, живой игрок пишет, лимит, сон, тишина 5–15 мин | возобновление ≤ 30 мин, иначе ENDING |
| CONVERSATION_ENDING | Естественное угасание: последний подкол, «ладно, я в бой», реакция, или просто тишина (без обязательного прощания) | — |
| SCENE_COMPLETED | Итоги сцены собраны | → MEMORY_UPDATE и RELATIONSHIP_UPDATE |
| MEMORY_UPDATE / RELATIONSHIP_UPDATE | Сохраняется только значимое; отношения, внутренние шутки, незавершённые темы | IDLE |

**Нелинейность:** из ACTIVE можно сразу в ENDING (тема не зашла), из PAUSED — в ENDING (не дождались), из
SCENE_CANDIDATES — в IDLE (уместной сцены нет). Сольная реплика (ambient) проходит CANDIDATES → INITIALIZED → ACTIVE (1
ход) → COMPLETED. Прерывание: живой игрок вмешался → сцена либо отвечает ему (ход `address`), либо уступает (PAUSED).

**Восстановление:** состояние, план и следующий запланированный ход хранятся в БД; после перезапуска Director
продолжает сцены, у которых `next_turn_at` не просрочен более чем на 10 мин, остальные закрывает без реплик.
