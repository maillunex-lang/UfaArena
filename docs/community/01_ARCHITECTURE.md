# 01. Dialogue Scene Architecture

## Принцип
Разговор — это **сцена** (scene): у неё есть канал, тема, участники, ход беседы, эмоциональный фон и итог. Сцена
**планируется детерминированно** (кто, когда, о чём и каким «ходом» отвечает) и **озвучивается** (текст реплики)
гибридно: языковой моделью, когда она доступна и в лимите, иначе — генеративной грамматикой шаблонов. Решения
о социальном поведении никогда не отдаются LLM целиком: модель пишет текст хода, который уже выбрал планировщик.

```
           ┌────────────── Director (тик, бюджет, сон) ──────────────┐
           │                                                         │
  события ─┤  Scene Planner ── Trigger Detector ── Participant Selector│
  игры,    │        │                                                 │
  чат,     │        ▼                                                 │
  время    │  Scene Store (ai_scenes, ai_scene_turns)  ◄── восстановление после рестарта
           │        │                                                 │
           │  Turn Scheduler (кто говорит, когда, кому, каким ходом)  │
           │        │                                                 │
           │  Move Realizer ─┬─ LLM Scene Writer (пакетно, по флагу)  │
           │                 └─ Template Grammar (всегда доступна)    │
           │        │                                                 │
           │  Style & Safety: Voice (speech.stylize) → Humor/Profanity│
           │                  → Content Guard → chat.clean()          │
           │        │                                                 │
           │  Pacing (banter: 10 с / тишина 5–15 мин) → ChatMessage   │
           │        │                                                 │
           │  Aftermath: Memory Extractor · Relationship Updater ·    │
           │             Interest Drift · Personality.evolve          │
           └─────────────────────────────────────────────────────────┘
```

## Модули (независимые, с узкими интерфейсами)
| Модуль | Ответственность | Интерфейс (эскиз) |
|---|---|---|
| `community/triggers.py` | Находит поводы для сцены: тишина в канале, событие игры, вопрос игрока, незавершённая тема, интерес | `detect(db, now) -> list[Trigger]` |
| `community/participants.py` | Подбор участников и наблюдателей (характер, интересы, отношения, онлайн, усталость) | `select(db, trigger, k) -> Cast` |
| `community/planner.py` | Решает: начинать ли сцену, тип, тема, тон, план «сюжета» беседы | `plan(db, trigger, cast) -> ScenePlan` |
| `community/scene.py` | Хранение и автомат состояний сцены; продвижение на шаг | `advance(db, scene, now) -> list[Turn]` |
| `community/turns.py` | Выбор следующего говорящего и «хода» (вопрос, ответ, шутка, спор, история, подкол, смена темы, уход) | `next_turns(scene) -> list[TurnSpec]` |
| `community/realize.py` | Текст хода: LLM-пакет или грамматика; анти-повтор | `realize(db, scene, specs) -> list[str]` |
| `community/offtopic.py` | Генерация свободных тем из интересов, памяти, времени суток, событий | `topics(db, cast) -> list[Topic]` |
| `community/humor.py` | Юмор, подколы, сленг, завуалированный мат, взрослый юмор — по профилю и отношениям | `season(text, speaker, target, ctx) -> str` |
| `community/guard.py` | Контент-ограничения (возраст, приватность, запреты), финальный `chat.clean()` | `check(text, channel, audience) -> Verdict` |
| `community/aftermath.py` | Память, отношения, интересы, «внутренние шутки», незавершённые темы | `apply(db, scene)` |
| `community/interests.py` | Профиль интересов и его дрейф | `profile(persona)`, `drift(...)` |

Все модули — в существующем процессе `ai-director` (новых постоянных процессов нет).

## Источники текста (Move Realizer)
1. **LLM Scene Writer** (если включено в «Речи» и есть лимит): **один запрос на несколько ходов сцены** (3–6 реплик
   разных участников по плану ходов, с профилями, отношениями и памятью сцены) — экономия лимитов. Результат
   разбирается построчно, проверяется Content Guard и анти-повтором; непрошедшие реплики заменяются грамматикой.
2. **Template Grammar** (всегда): ходы × темы × тон × голос, с заменяемыми частями (вступление, суть, хвост,
   реакция), личными присказками, темами из интересов и памяти; анти-повтор по канонической форме.
3. Заготовки `banter.SCRIPTS` — как «семена» игровых сцен.

## Совместимость
- Старый путь (`banter.keep_alive`, `start_conversation`) остаётся запасным и используется, если Scene Engine
  выключен (флаг `community.enabled`) или упал.
- Темп, сон без игроков, лимиты нагрузки, приватность, метка «ИИ» — без изменений и обязательны для сцен.
