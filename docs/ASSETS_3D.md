# 3D-ресурсы через админку (без нового APK)

Админка → «Графика»:
- **«3D-модели героев и врагов»** — GLB героя/врага (`models/heroes/<код>.glb`). После загрузки: сопоставить анимации
  файла действиям игры (стойка, бег, атака, умение, ульта, удар, смерть, победа) и масштаб → «Опубликовать». Сервер
  кладёт модель в пакет `ui.models3d` и создаёт `looks/<код>.json` (`rig: content:art/models/heroes/<код>.glb`).
  **Работает в нынешнем приложении** (механизм `looks` есть с 0.6.x).
- **«3D-карты и сцены боя»** — 3D-карта региона (`maps/regions/<регион>.glb`, экран кампании) и сцена боя для каждого
  типа местности и для боссов (`maps/battle/<местность>.glb`, `maps/battle/boss.glb`). **Нужна версия приложения новее
  0.7.5** (следующая сборка APK); старое приложение показывает встроенные сцены.

Требования к файлам: binary glTF 2.0 (`.glb`), до 40 МБ, Y вверх, 1 единица = 1 м, начало координат у ног (для карт —
в центре на уровне земли), лицом к +Z; для мобильных: героям до ~15 тыс. треугольников, сценам боя до ~50 тыс., картам
регионов до ~80 тыс.; текстуры 1024–2048 px внутри файла. Героям нужен скелет и анимации (Idle и Run зацикленные).
Сцена боя: ровный центр ~10×6 м под отряды, декорации по краю. Карта региона: путь снизу вверх (~12×30 м), ровные площадки
под точки этапов — точки игра ставит по координатам из редактора карты.

3D-пакет публикуется отдельно от картинок: замена картинки не заставляет игроков заново скачивать модели.
