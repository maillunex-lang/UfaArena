# Матрица управления игрой (FULL CONTROL)

Категории: **A** — конфигурация (числа, таймеры, флаги), **B** — контент (сущности, ассеты), **C** — интерфейс,
**D** — логика (алгоритмы и правила).

Применение изменения:
- **S** — серверное, действует без обновления клиента (после активации версии);
- **P** — через контент-пакет (без нового APK, клиент скачивает);
- **APK** — нужен новый клиент (меняется код).

Состояние: из аудита [Код]; «Источник сейчас» — где данные лежат сегодня.

## 2. Категория D — что параметризуется, а что требует кода

| Логика | Параметризуется безопасно (A) | Требует кода и APK/сервера (D) |
|---|---|---|
| Бой (`battle_sim.py`, серверный) | коэффициенты урона/защиты, крит, КД, длительности, приоритеты целей из списка, скорость | новые типы эффектов, новые формулы, новые правила хода |
| Формулы прогрессии | таблицы опыта, капы, множители звёзд/редкости | новый тип прогрессии (таланты, ветки) |
| Экономика | все числа, таблицы наград, цены | новые валюты (влияют на клиент и БД) |
| AI | веса, вероятности, лимиты, расписания, тексты/шаблоны, промпты | новые типы поведения/задач Director |
| Механики | включение, окна, лимиты | новая механика = новый код |
| UI | раскладка, стили, тексты, видимость, порядок, иконки | новый компонент, новое действие кнопки, новый экран с логикой |

Правило: **админ выбирает из перечня, который знает код** (типы эффектов, действия кнопок, компоненты, флаги).
Расширение перечня — релиз. Удалённого исполнения кода нет (ни GDScript, ни Python, ни SQL, ни выражений-формул
в виде строк для `eval`). Для формул допускается только **табличное** или **параметрическое** задание
(кривая по точкам, коэффициенты известной функции).

## 3. Нельзя никогда (жёсткие ограничения)

- Удалять/обнулять прогресс, валюты, героев игроков массово (только адресные операции поддержки с аудитом).
- Менять уже опубликованную версию (только новая версия).
- Включать реальные платежи из Studio (только серверная переменная окружения [Код: `URALIA_PAYMENTS_COMMERCIAL_ALLOWED`]).
- Отправлять секреты в клиентские пакеты (валидатор блокирует ключи с именами `*key*`, `*secret*`, `*token*`).
- Снимать ограничения D-C1 (возраст) через конфиг.
