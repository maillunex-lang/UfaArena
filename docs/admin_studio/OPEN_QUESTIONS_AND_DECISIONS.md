# Открытые вопросы и решения на согласование

Для каждого — рекомендация. Владелец отвечает «принять» или выбирает другой вариант.

| ID | Вопрос | Варианты | Рекомендация |
|---|---|---|---|
| Q-T1 | Технология Studio | A Compose · B Flutter · C React+TS+Capacitor · D Godot | **C** + Godot только для Runtime Preview (TECHNOLOGY_SELECTION) |
| Q-T2 | Где собирать Studio APK (нужны Node + Gradle) | в облачной сессии · CI GitHub Actions · у владельца | **CI GitHub Actions** (воспроизводимо, без нагрузки на VPS) |
| Q-S1 | TLS и домен | купить домен + Let's Encrypt (Caddy) · самоподписанный сертификат с закреплением в APK | **домен + Let's Encrypt**; без домена — самоподписанный как временная мера |
| Q-S2 | Обязательный TOTP | для всех · только для публикации в prod · не нужен | **для ролей с правами на PRODUCTION** |
| Q-S3 | Судьба общего токена | удалить сразу · аварийный вход · оставить как есть | **аварийный вход** с алертами, выключаемый env |
| Q-S4 | «Четыре глаза» | всегда второй утверждающий · для владельца-одиночки — step-up | **step-up для одиночки**, второй утверждающий — когда в команде ≥ 2 админов |
| Q-E1 | STAGING | теневой на том же VPS · отдельный сервер | **теневой** сейчас, отдельный — при росте |
| Q-E2 | Переход APK с канала `dev` на `stable` | сразу в следующей сборке · после запуска Studio | **в сборке этапа 7**; на переходе оба канала держат одинаковые публикации |
| Q-P1 | Применение изменений из текущей админки | оставить мгновенным до готовности Studio · сразу перевести на DRAFT/APPROVAL | **оставить** до этапа 2, затем модуль за модулем |
| Q-P2 | ZIP-патчи в Studio | применять сразу (как v1) · только как changeset | **changeset**; «быстрый режим» — для DEV/STAGING |
| Q-P3 | Автооткат по ошибкам клиентов | автоматически при пороге · только алерт | **алерт + кнопка**; автооткат — позже, когда будет статистика |
| Q-U1 | Глубина Pro-редактора | только окружение экранов и стили · полная сборка экранов из компонентов | **поэтапно**: сначала стили/порядок/видимость, полная сборка — для простых экранов |
| Q-U2 | Свободное позиционирование (`Free`) | разрешить везде · только в отдельных контейнерах | **только в специальных контейнерах** (контейнерная раскладка Godot устойчивее на разных экранах) |
| Q-U3 | Альбомная ориентация | поддерживать · нет | **нет** (игра только портретная [Код]) |
| Q-L1 | Локализация | делать · отложить | **отложить** до решения о выходе на другие языки |
| Q-A1 | SVG | конвертация на сервере в PNG · не поддерживать | **не поддерживать** на старте |
| Q-G1 | Предметы и экипировка | проектировать сейчас · после Studio | **отдельный игровой проект**, затем подключение к реестру |
| Q-M1 | Внешний мониторинг (Prometheus/Grafana) | ставить · не ставить | **не ставить** на 2 ГБ VPS; встроенный раздел Studio |

## Уже принятые решения (из ТЗ владельца)

Глубина управления — FULL; редактор — HYBRID (Simple + Pro, одна модель данных); применение — CONTROLLED
(DRAFT → PREVIEW → VALIDATION → APPROVAL → PUBLISHED → ACTIVE, + REJECTED, FAILED, ROLLED_BACK; Published ≠ Active ≠
Applied); без удалённого исполнения кода; ZIP-патчи с заданиями для ИИ по каждой настройке (2026-11-02, v1 реализован).
