# Изменения редизайна 0.7

## Оболочка и дизайн-система
* Новая дизайн-система Night Turquoise + Ancient Gold (`UI.gd`): токены, шкалы, компоненты, состояния.
* Шрифты: Manrope (интерфейс) + Philosopher (заголовки) + подмножества Noto для символов и эмодзи.
* Нижняя навигация: Главная · Герои · Поход · Гильдия · Мир · Ещё; верхняя панель: профиль, ресурсы, колокольчик.
* Меню без 3D-сцены (градиентный фон) — легче для GPU и батареи.

## Экраны
* Главная — дашборд из реальных данных (`/player/summary`).
* Новые: Мир, Ещё, Профиль, Инвентарь, центр уведомлений.
* Герои: вкладки детали, горизонтальная прокрутка фракций.
* Поход: компактная подготовка к бою.
* Бой: результат с раскрывающейся статистикой; кнопка «На главную» вместо «В крепость».
* Задания: категории Ежедневные · Основные · Побочные · Достижения · Гильдия · События.
* Центр гильдии: Обзор · Участники · Босс · Магазин · Задания · Рейтинг · Война (+ развитие и управление).
* Настройки: сгруппированы, одна громкость, масштаб UI, меньше анимаций, контраст, цветовая кодировка, вибрация,
  лимит FPS, экономия батареи, категории уведомлений, кэш, аккаунт.
* Онбординг: кнопка «Пропустить», подсказка над навигацией, без наложений.

## Сервер
* `GET /player/summary`.
* Восстановление доступа: `/auth/recover`, `/auth/recovery-code`, `/auth/password`; миграция 0008 (`users.recovery_hash`).
* Магазин гильдии: `GET /guilds/shop`, `POST /guilds/shop/{code}/buy` (без изменения схемы).
* Раздача Web-версии на `/play` (опционально), том `./web` в docker-compose.

## Удалено
* `ModesScreen` (старый экран «Режимы»): его функции перенесены в «Мир» и «Ещё». Два конкурирующих интерфейса не остались.

## Сборки
* Android 0.7.0 (versionCode 12), arm64.
* Web (Godot Web без потоков, Compatibility-рендер только для web).

## 0.7.2 — доработки по сверке с промптом
* Герои: боевой рейтинг ⚔ на каждой карточке, фильтр по уровню, направление сортировки.
* Призыв: карточка каждого реального пула (цена, шансы, гарантия); перед призывом окно с полной стоимостью, остатком, шансами, гарантией и последствиями.
* Центр событий: Все · Ежедневные · Недельные · Сезонные · Особые · Соревнования · Награды · Календарь · Летопись; архив прошедших убран (вне объёма по ТЗ).
* Обучение: подсказки при первом открытии 14 разделов (не повторяются), обучение пропускается касанием подсказки, в настройках — повтор подсказок и вступления.
* Бой: в статистике награды, опыт игрока и повышение уровня, прогресс похода (`/campaign/{code}/complete` возвращает `exp_gained`, `level`, `level_up`, `campaign_progress` — новые поля).
* Мини-чат поверх любого экрана (кнопка в верхней панели), «Развернуть» — полный чат.
* Всплывающие уведомления: одно объединённое сообщение о новом (дозор полон, задания, почта, друзья, подарки, заявки в гильдию, начало и скорое окончание событий) с учётом категорий из настроек.
* Состояния: «Переподключение» с автоповтором и обратным отсчётом, после связи экран обновляется с сервера; «Частичные данные» в центре событий и профиле.
* Анимации: эффекты наград и редкости (`UI.celebrate`), переходы разделов и плавная смена сцен; всё выключается «Меньше анимаций».
* Глобальный поиск (верхняя панель): разделы, герои, игроки, гильдии; релевантность, без истории.
* Карта мира: регионы на реальных местах Южного Урала, маршрут, статусы, переход к главе; фон заменяется в админке.
* Настройки: «Приватность» (скрыть статус в сети, заблокированные), «Сеть и трафик», «Память», «Язык», «Обучение». В «Друзьях» вкладка «Блок» (`/social/friends` возвращает `blocked`).
* Исправлено: гонка при отрисовке портретов героев (кадр мог сниматься до готовности камеры) — портреты больше не превращаются в «крупные пятна».

## 0.7.4 — решения с последствиями (этап S2 лора)
* В сюжетных сценах появились решения: кнопки поверх диалога, «Пропустить» останавливается на непринятом решении, решение нельзя изменить.
* Сервер хранит решения и сюжетные флаги (миграция 0009 — таблицы `story_choices`, `player_story_flags`), проверяет доступность и не даёт переиграть; реплики сцен показываются по флагам.
* Пролог: «дорога через бор» (судьба Тимера), «голос в осколке» (тон Древнего), «ночлег каравана» (Орден / Последователи / никто) — с последствиями в следующих сценах.
* Профиль → «Решения»: принятые решения и решения, до которых игрок уже дошёл, но не принимал (например, этапы пройдены до обновления).

## 0.7.5 — Караван (этап S4 лора)
* Экран «Караван» вместо «Крепости»: вкладки «Модули», «Совет», «Маршрут»; на главной — значок каравана с таймером пути.
* Модули: прежние здания под новыми названиями (уровни и бонусы сохранены) + Библиотека, Исследовательский центр, Оборонительные башни; Жилые модули открыты.
* Совет каравана: настроение и реплики шести советников без чисел; ближайший советник даёт бонус.
* Маршрут: карта с дорогами Дыхания, отметкой каравана и доступными землями; поездка занимает время; земля стоянки даёт дозору местные припасы.
* Старый экран крепости удалён (две конкурирующие версии не остаются). Миграция 0010 (`player_caravans`).
