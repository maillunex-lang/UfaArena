# Изменения редизайна 0.7

## Оболочка и дизайн-система
* Новая дизайн-система Night Turquoise + Ancient Gold (`UI.gd`): токены, шкалы, компоненты, состояния.
* Шрифты: Manrope (интерфейс) + Philosopher (заголовки) + подмножества Noto для символов и эмодзи.
* Нижняя навигация: Главная · Герои · Поход · Гильдия · Мир · Ещё; верхняя панель: профиль, ресурсы, колокольчик.
* Меню без 3D-сцены (градиентный фон) — легче для GPU и батареи.

## Экраны
* Главная — дашборд из реальных данных (`/player/summary`).
* Новые: Мир, Ещё, Профиль, Инвентарь, центр уведомлений.
* Герои: вкладки детали, горизонтальная прокрутка фракций.
* Поход: компактная подготовка к бою.
* Бой: результат с раскрывающейся статистикой; кнопка «На главную» вместо «В крепость».
* Задания: категории Ежедневные · Основные · Побочные · Достижения · Гильдия · События.
* Центр гильдии: Обзор · Участники · Босс · Магазин · Задания · Рейтинг · Война (+ развитие и управление).
* Настройки: сгруппированы, одна громкость, масштаб UI, меньше анимаций, контраст, цветовая кодировка, вибрация,
  лимит FPS, экономия батареи, категории уведомлений, кэш, аккаунт.
* Онбординг: кнопка «Пропустить», подсказка над навигацией, без наложений.

## Сервер
* `GET /player/summary`.
* Восстановление доступа: `/auth/recover`, `/auth/recovery-code`, `/auth/password`; миграция 0008 (`users.recovery_hash`).
* Магазин гильдии: `GET /guilds/shop`, `POST /guilds/shop/{code}/buy` (без изменения схемы).
* Раздача Web-версии на `/play` (опционально), том `./web` в docker-compose.

## Удалено
* `ModesScreen` (старый экран «Режимы»): его функции перенесены в «Мир» и «Ещё». Два конкурирующих интерфейса не остались.

## Сборки
* Android 0.7.0 (versionCode 12), arm64.
* Web (Godot Web без потоков, Compatibility-рендер только для web).
