# Экраны

Источник данных указан для каждого экрана: всё приходит с сервера, тестовых данных в интерфейсе нет.

## Нижняя навигация
| Раздел | Экран | Содержимое | Данные |
|---|---|---|---|
| Главная | `HomeScreen` | Игровая панель (гибрид §5): сверху полоса прогресса похода; слева иконки Задания · Почта · Друзья · Чат · Рейтинг с бейджами; справа События (таймер), сундук «Дозор» (таймер до заполнения, сбор в одно касание), Рейды, Арена, Турниры; в центре реальный отряд (портреты, уровни, сила), уровень и опыт игрока; внизу ежедневные задания и большие кнопки Магазин · Призыв · В бой | `/player/summary`, `/rewards/afk/claim` |
| Герои | `HeroesScreen` | Сетка карточек; фильтры фракция/редкость/класс, поиск, сортировка; деталь с вкладками Характеристики · Навыки · Экипировка · Артефакты · Вознесение | `/heroes`, `/heroes/{id}/level-up` |
| Поход | `CampaignScreen` | Карта глав; компактная подготовка к бою: ваш отряд, противники, награды, «Изменить отряд», «В бой» | `/campaign` |
| Гильдия | `GuildScreen` | Центр гильдии: Обзор · Участники · Босс · Магазин · Задания · Рейтинг · Война, затем Технологии · Казна · Заявки · Управление · Настройки | `/guilds/*`, `/raids`, `/rankings/guilds` |
| Мир | `WorldScreen` | Каталог: Регионы, События, Боссы, Испытания, Экспедиции, Турниры; Подземелья, Башня, Тайны — «Скоро»; список регионов | `/campaign`, `/events/world` |
| Ещё | `MoreScreen` | Группы карточек: Предметы, Прогресс, Социальное и сервисы, Управление | бейджи из `/player/summary` |

## Вторичные экраны
| Экран | Содержимое |
|---|---|
| `ProfileScreen` | Портрет, имя, титул, ID, уровень, VIP, рейтинг, гильдия; вкладки Обзор · Герои · Достижения · История |
| `InventoryScreen` | Сетка валют с точными количествами и контекстной панелью; предметы/экипировка — состояние «закрыто» |
| `QuestsScreen` | Ежедневные · Основные · Побочные · Достижения · Гильдия · События |
| `EventsScreen` | Центр событий: Сейчас · Летопись · Прошедшие |
| `ShopScreen` | Табличка «Магазин», левое меню разделов, баннер реального предложения, сетка товаров 3 колонки с картинками, золотыми кнопками цены и метками из данных («−N%», «Выгодно», «Популярно», «Ограничено»), окно покупки с полным составом; тестовый режим помечен |
| `SummonScreen` | Призыв с открытыми шансами и гарантией |
| `MailScreen`, `ChatScreen`, `FriendsScreen`, `RankingsScreen`, `ArenaScreen`, `RaidsScreen`, `TournamentsScreen`, `FortressScreen`, `FormationScreen` | Существующие функции в новой оболочке |
| `SettingsScreen` | Аккаунт · Графика и производительность · Звук · Интерфейс и доступность · Уведомления · ИИ-жители · Данные и обновления · О игре |
| `Battle` | Минимальный HUD (этап, сила сторон, таймер, скорость, «Пропуск»); результат с раскрывающейся «Статистикой боя» (урон, получено, лечение, доля урона) |

## Состояния
Каждый сетевой экран имеет: загрузку (скелетон), пустое состояние, ошибку и «нет связи» с кнопкой «Повторить»,
закрытое состояние (`locked`) для функций, которых нет на сервере.

## Честно закрытые функции (нет серверной логики — показаны как «Скоро»/«закрыто», без фиктивных данных)
Экипировка и артефакты героев, предметы инвентаря, Подземелья, Башня, Тайны.
