## Функциональный / регрессионный сквозной тест клиента (`URALIA_E2E`, `tools/E2E.gd`)
Реальный клиент против локального сервера, новый гость. Шаги: вход → сюжет → «В бой» с главной → подготовка → бой 1-1 →
результат → почта → «Ещё» → Призыв ×1 → Герои → деталь → повышение уровня → Формация → сохранение отряда → Главная →
дозор «Забрать» → Задания → Крепость «Улучшить» → бой 1-2 → **перезапуск приложения** (прогресс 1-1, 1-2 и золото
сохранились: `RESTART … -> OK`) → **офлайн** (баннер показан) → «Повторить» (восстановлено). Итог: `E2E_DONE`.
Замечание: в шаге «Задания» на вкладке «Ежедневные» не оказалось готовых к получению наград — это ожидаемо для нового игрока.

## Визуальный обход (`URALIA_E2E_UI`, `tools/E2EUI.gd`)
Открывает 20 экранов (Главная, Герои, Поход, Гильдия, Мир, Ещё, Профиль, Инвентарь, Задания, События, Магазин,
Настройки, Почта, Призыв, Друзья, Чат, Рейтинг, Арена, Рейды, Крепость) и центр уведомлений, сохраняет скриншоты.
Ошибок скриптов: 0. По скриншотам исправлены: наложение сюжетного диалога, перенос текста в карточке дозора,
подсказка онбординга поверх карточек, переключатели настроек, обрезка вкладок фракций.
