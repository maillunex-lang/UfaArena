# Дизайн-система «Night Turquoise + Ancient Gold»

Файл: `client/src/ui/UI.gd`. Стиль — Premium Dark Glass: тёмные полупрозрачные поверхности, бирюзовые акценты, золото для
главных действий. Размытие стекла включается **только** на высоком качестве графики (`Gfx.setting("blur")`).

## Цвета
| Токен | Значение | Назначение |
|---|---|---|
| `BG` | `#0b1215` | фон |
| `SURFACE` / `SURFACE_2` | `#121c21` / `#182830` | карточки, панели |
| `LINE` | `#2c4549` | рамки |
| `TEAL` / `TEAL_DEEP` | `#3fd0c3` / `#15605a` | акцент, прогресс, вторичные кнопки |
| `GOLD` / `GOLD_DARK` | `#efcf86` / `#a37a2c` | главные действия, заголовки, награды |
| `TEXT` / `MUTED` | `#eef2f0` / `#a9bab7` | текст / вторичный текст |
| `SUCCESS` / `WARNING` / `DANGER` | `#5fc98a` / `#e8a33d` / `#e0604f` | статусы |
| `RARITY[1..6]` | серый → зелёный → синий → фиолетовый → золотой → красный | редкость |

Статусные цвета берутся через `UI.ok_color()` / `UI.bad_color()`: в режиме «Альтернативная цветовая кодировка» они
становятся синим/оранжевым, а редкость дополнительно кодируется числом звёзд (`★5`).

## Типографика (гибридная)
* Интерфейс — **Manrope** 500/700 (`FONT_REG`, `FONT_BOLD`).
* Заголовки — **Philosopher Bold** (`FONT_TITLE`).
* Резервные шрифты символов и эмодзи — подмножества **Noto Sans Symbols / Symbols 2 / Math / Noto Emoji**, затем системные.
* Шкала `FS`: caption 24 · body 28 · body_l 31 · h3 34 · h2 40 · h1 50 (холст 1080×1920). Минимальный размер текста 24.

## Отступы и радиусы
`SP`: xs 6 · s 10 · m 16 · l 24 · xl 32. `R`: s 12 · m 18 · l 24 · pill 60.

## Иконки
`src/ui/GameIcon.gd` — векторные duotone-иконки (золото + бирюза), рисуются кодом: валюты, разделы навигации,
колокольчик, корона, рейтинг, чат, эмблемы фракций.

## Движение
Нажатие кнопки — короткое масштабирование 0.97; появление панелей — `UI.pop_in`. При «Меньше анимаций»
(`UI.reduce_motion()`) анимации нажатия и появления отключаются.

## Доступность
Высокая контрастность (`UI.high_contrast()`: непрозрачные панели, толще обводка текста), альтернативная цветовая
кодировка, масштаб интерфейса 0.9/1.0/1.1, вибрация на нажатия (отключаемая). Язык — только русский.
