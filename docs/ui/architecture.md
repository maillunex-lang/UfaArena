# Архитектура интерфейса (редизайн 0.7)

Редизайн выполнен **внутри существующей архитектуры** клиента Godot 4.5.1, новый проект не создавался.

## Слои
| Слой | Где | Роль |
|---|---|---|
| Автозагрузки | `src/autoload/` | `Config` (настройки, `user://settings.cfg`), `Api` (HTTP, токены, идемпотентность), `Game` (состояние игрока с сервера), `Content` (пакеты контента), `Gfx` (качество, FPS, масштаб UI, громкость), `Sfx`, `Models` (3D-модели и портреты), `Router` (сцены, тосты, ошибки) |
| Оболочка | `src/scenes/Main.gd` | Верхняя панель (профиль, ресурсы, колокольчик), нижняя навигация из 6 разделов, контейнер экранов, фон, онбординг |
| Дизайн-система | `src/ui/UI.gd` | Токены (цвета, отступы, радиусы, шрифты) и все общие компоненты |
| Экраны | `src/screens/*.gd` | Каждый экран — скрипт с `setup(main, params)`; открывается `main.open(name, params)` |
| Оверлеи | `src/ui/Notifications.gd`, `StoryDialog.gd`, `UpdateDialog.gd`, `PlayerPopup.gd` | Центр уведомлений, сюжетные диалоги, обновление, карточка игрока |
| Бой | `src/scenes/Battle.gd` | Минимальный HUD, экран результата со статистикой |

## Навигация
`Main.NAV` — фиксированный порядок: **Главная · Герои · Поход · Гильдия · Мир · Ещё**.
`Main.NAV_OF` задаёт, какой раздел подсвечен для вторичных экранов (например, «Призыв» → «Ещё», «Арена» → «Мир»).

## 3D-сцена и производительность
`main.use_world(kind)`:
* `"none"` — 3D-сцена выгружается, рисуется лёгкий градиентный фон (Главная, Мир, Ещё, Задания, Настройки, социальные экраны);
* `"hub"` — крепость (Герои — витрина 3D-модели героя, Призыв, Крепость);
* `"campaign"` — карта похода.

Меню без 3D заметно легче для GPU и батареи (замеры — `tests.md`).

## Данные
Интерфейс показывает только серверные данные. Для главной и колокольчика добавлен один агрегирующий
read-only эндпоинт `GET /player/summary` (`server/app/modules/hub.py`): он только читает существующие системы.

## Серверные изменения редизайна (все обоснованы функциями ТЗ)
| Изменение | Зачем | Схема БД |
|---|---|---|
| `GET /player/summary` | Главная-дашборд и центр уведомлений одним запросом | без изменений |
| `POST /auth/recover`, `/auth/recovery-code`, `/auth/password` | Восстановление доступа и смена пароля (SMTP на сервере нет) | миграция 0008: колонка `users.recovery_hash` |
| `GET /guilds/shop`, `POST /guilds/shop/{code}/buy` | Раздел «Магазин» центра гильдии: тратить уже начисляемые гильдейские знаки | без изменений (лимиты считаются по журналу кошелька) |
| Раздача Web-версии на `/play` | Web-версия игры | без изменений |
Существующие контракты не менялись: `/auth/link` лишь добавил в ответ поле `recovery_code`.
