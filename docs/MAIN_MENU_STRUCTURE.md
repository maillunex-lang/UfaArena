# Структура главного меню: полное изменение (вручную и ZIP-патчем)

Главный экран можно собрать **с нуля**: строки, колонки, сетки и панели, а в них — полоса похода, отряд, ежедневные
задания, круглые и большие кнопки, плитки, тексты, картинки и отступы. Каждая кнопка ведёт туда, куда вы укажете.
Работает в игре с версии **0.7.8**. Старые версии показывают простой режим (колонки и большие кнопки из «Главного экрана»).

## Где

Админка → «Редактор игры» → «Интерфейс» → **«Структура главного»**.
1. «Создать структуру из текущего главного экрана». Получится точная копия того, что сейчас видят игроки.
2. Справа:
   - **Обязательные элементы** с отметками ✓/✗;
   - свойства выбранного элемента;
   - «Добавить» — новый элемент попадает внутрь выбранного контейнера или встаёт после выбранного элемента;
   - **дерево**: перетаскивайте элементы за название в любой контейнер и на любое место.
3. Слева — макет телефона. Нажатие на элемент в макете выбирает его. Макет приближённый, точный вид — в игре.
4. «Опубликовать». Откат и сброс работают как во всём «Интерфейсе».
5. «Выключить структуру» возвращает простой режим.

## Элементы

| Тип (`type`) | Что это | Поля |
|---|---|---|
| `vbox` | Колонка: элементы сверху вниз | `children`, `sep`, `align`, `min_w`, `expand`, `ratio`, `hidden` |
| `hbox` | Строка: элементы слева направо | то же |
| `grid` | Сетка из N колонок | то же + `columns` 1…6 |
| `panel` | Панель с фоном, внутри элементы сверху вниз | то же, что у `vbox` |
| `campaign_strip` | Полоса похода (прогресс кампании, ведёт в поход) | `expand`, `hidden` · **не больше одной** |
| `squad` | Отряд игрока (портреты, сила, ведёт в «Отряд») | `expand`, `ratio`, `hidden` · **не больше одной** |
| `daily_strip` | Ежедневные задания (ведёт в «Задания») | `expand`, `hidden` · **не больше одной** |
| `side` | Круглая кнопка с подписью: счётчики и таймеры (почта, задания, события, дозор, караван) | `id`, `label`, `icon`, `hidden` |
| `big` | Большая кнопка | `id`, `label`, `icon`, `color` `#RRGGBB`, `ratio` 0.5…3 |
| `tile` | Плитка, как в «Ещё» | `id`, `label`, `icon` |
| `text` | Текст | `text` до 200, `size` caption / body / title / h1, `color`, `align` start / center / end |
| `image` | Картинка | `path`: `ui/home/banner_1.png` … `banner_4.png` (также `ui/home_bg.png`, `ui/world_map.png`), `height` 40…1200 |
| `spacer` | Отступ | `size` 0…800 px |

- `id` у кнопок — **куда ведёт**: любой раздел (`heroes`, `shop`, `summon`, `arena`, `events`, `guild`, `caravan`,
  `mail`, `quests`, `rankings`, `settings`…). Особые действия:
  - `battle` — бой со следующим этапом;
  - `afk` — **собрать дозор** (работает с любой кнопки, в том числе из «Ещё»);
  - `chat` — мини-чат;
  - `search` — поиск;
  - `achievements` — достижения.

  Полный список в задании для ИИ и в выпадающем списке.
- `sep` — отступ между элементами контейнера, 0…80 px; `min_w` — минимальная ширина, px (игра рисует в 1080 px по ширине).
- `expand` — растягиваться: в строке по ширине (`ratio` — вес), в колонке по высоте. Обычно растягивают отряд или
  среднюю строку, чтобы экран был заполнен.
- Ограничения: до 120 элементов, вложенность до 8, корень — только `vbox`.
- Картинки-баннеры загружаются в «Графика» → «Главный экран» (баннеры 1–4, 1080×360). Пока картинка не загружена,
  элемент в игре просто не показывается.

## Обязательные элементы (что нельзя убрать)

Как бы ни выглядело меню, игрок должен попадать сюда. Сервер проверяет это при каждой публикации и при каждом ZIP-патче.

| Что | Где должно быть (достаточно одного места) | Пути |
|---|---|---|
| Нижняя панель: «Главная» и «Ещё» | всегда видимы | `nav[id=home]`, `nav[id=more]` |
| **Вход в бой / поход** | полоса похода, или кнопка `battle` / `campaign` на главном, или «Поход» в нижней панели, или плитка в «Ещё» | `home.tree…campaign_strip` · `home.tree…{id: battle\|campaign}` · `nav[id=campaign]` · `more.groups[].items[id=campaign\|battle]` |
| **Сбор дозора** (AFK-награды) | кнопка `afk` на главном или плитка в «Ещё» | `home.tree…{id: afk}` · `more.groups[].items[id=afk]` |
| **Задания** | ежедневные задания или кнопка `quests` (главный, панель, «Ещё») | `home.tree…daily_strip` · `…{id: quests}` |
| **Почта** (подарки и компенсации) | кнопка `mail` где угодно | `…{id: mail}` |
| **Настройки** (выход, возраст, приватность) | кнопка `settings` где угодно | `…{id: settings}` |

Скрытые элементы (`hidden: true`, в том числе внутри скрытого контейнера) не считаются. В простом режиме (без
`home.tree`) проверяются блоки, колонки и большие кнопки.

## ZIP-патч

Только структура главного (остальное меню не меняется):
```json
{
  "format": "uralia-patch/1",
  "title": "Новый главный экран",
  "author": "Claude",
  "changes": [{"type": "ui_layout", "merge": {"home": {"tree": {
    "type": "vbox", "sep": 12, "children": [
      {"type": "text", "text": "Добро пожаловать в Уралию!", "size": "title", "align": "center"},
      {"type": "image", "path": "ui/home/banner_1.png", "height": 360},
      {"type": "campaign_strip"},
      {"type": "panel", "children": [
        {"type": "grid", "columns": 4, "sep": 8, "children": [
          {"type": "tile", "id": "afk", "label": "Дозор", "icon": "afk"},
          {"type": "tile", "id": "quests", "label": "Задания", "icon": "quests"},
          {"type": "tile", "id": "mail", "label": "Почта", "icon": "mail"},
          {"type": "tile", "id": "arena", "label": "Арена", "icon": "arena"}]}]},
      {"type": "hbox", "expand": true, "children": [
        {"type": "squad", "expand": true},
        {"type": "vbox", "min_w": 150, "align": "center", "children": [
          {"type": "side", "id": "events", "label": "События", "icon": "events"},
          {"type": "side", "id": "raids", "label": "Рейды", "icon": "shulgan"}]}]},
      {"type": "hbox", "sep": 8, "children": [
        {"type": "big", "id": "summon", "label": "Призыв", "icon": "summon", "color": "#4b2a7a", "ratio": 1},
        {"type": "big", "id": "battle", "label": "В бой!", "icon": "arena", "color": "#8e1b1b", "ratio": 2}]}
    ]}}}}]
}
```
- Убрать структуру и вернуть простой режим: `{"type": "ui_layout", "merge": {"home": {"tree": null}}}`.
- Задание для ИИ: в структуре нажмите «🤖 ИИ / патч» или откройте «ZIP-патчи и ИИ» → «Интерфейс: кнопки и экраны» →
  «Скопировать задание». В задание автоматически попадают текущая структура, все типы элементов, иконки, действия и
  обязательные элементы.
- Порядок такой: «Проверить патч» (покажет «было → станет» или какой обязательный элемент пропал) → «Применить» →
  при необходимости откат последнего патча.
