# URALIA Living World AI — ДОРОЖНАЯ КАРТА

> Этапы мастер-ТЗ, сгруппированные по фазам, с зависимостями. Каждый этап: MASTER SPEC CHECKPOINT → реализация →
> тесты → документы → проверка соответствия. APK — один раз в конце (фаза 8).

## Фазы и этапы
| Фаза | Этапы ТЗ | Содержание | Зависит от |
|---|---|---|---|
| 1. Аудит и проектирование | 0 | Аудит кода ✅, аудит VPS (данные от заказчика), решения D-01…D-12 | — |

| 3. Личности и поведение | 2, 4, 7, 14 | Архетипы как данные, черты/амбиции/привычки, эволюция личности; слои силы (новичок…элита); речь (шаблоны + опц. локальная модель); биография, память, архив, версии | Ф2 |
| 4. Социальная система | 6, 8, 9, 16 | Граф отношений и группы; каналы чата (+событийный/региональный — D-11); гильдии ИИ: выборы, роли, союзы (D-12); общение с реальными игроками с учётом приватности | Ф3 |

| 8. Интеграция и выпуск | 20 | Регрессия всего проекта, проверка отключения Director, документы, **единственная сборка APK**, установка и сценарии | Всё |

## Зависимости модулей
```
AI Director ─┬─ Activity Scheduler ── Population Manager
             ├─ Task/Event queues ─┬─ Behavior Engine ── Personality Engine
             │                     ├─ Progression Engine ┐
             │                     ├─ PvP Engine         ├─ игровые сервисы (бой, кампания, призыв, арена, гильдии)
             │                     ├─ Economy Engine     ┘
             │                     ├─ Social Engine ── Chat Engine ── Guild Engine
             │                     └─ Event Engine
             ├─ Memory Manager (все модули пишут в память)
             ├─ Analytics
             └─ Admin API ── AI Control Center
```

## Что меняется в клиенте (минимально)
Метки «ИИ» уже есть везде. Возможные дополнения: событийный/региональный каналы чата (D-11), союзы гильдий (D-12),
настройка «не получать личные сообщения от ИИ». Все — в одном финальном APK.

## Статус фаз
- Фаза 1 ✅ аудит кода и VPS.
- Фаза 2 ✅ базовое ядро.
- Фаза 3 ✅ личности, слои силы, речь, память.
- Фаза 4 ✅ отношения, каналы, гильдии и союзы, общение с игроками.
- Фаза 5 ✅ игра по правилам, PvP, экономика, события.

## Контрольный список следующего этапа (Фаза 6: этап 18 — AI Control Center)
1. Перечитать мастер-ТЗ: этап 18, разделы 7, 8; решение D-08.
2. Свести вкладку «ИИ-жители» в полноценный Control Center: обзорная панель (метрики, графики активности, нагрузка),
   конструкторы (архетипы, расписания, поведение), граф связей, журнал всех действий администраторов с откатом.
3. Учётные записи администраторов с ролями (владелец, оператор ИИ, модератор, наблюдатель) — D-08; общий токен — только
   владельцу на переходный период.
4. Импорт/экспорт настроек ИИ целиком (резервная копия конфигурации), массовые операции над персонажами.
5. Тесты: права ролей на каждый маршрут, откат, импорт/экспорт.
