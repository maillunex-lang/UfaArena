## Зависимости модулей
```
AI Director ─┬─ Activity Scheduler ── Population Manager
             ├─ Task/Event queues ─┬─ Behavior Engine ── Personality Engine
             │                     ├─ Progression Engine ┐
             │                     ├─ PvP Engine         ├─ игровые сервисы (бой, кампания, призыв, арена, гильдии)
             │                     ├─ Economy Engine     ┘
             │                     ├─ Social Engine ── Chat Engine ── Guild Engine
             │                     └─ Event Engine
             ├─ Memory Manager (все модули пишут в память)
             ├─ Analytics
             └─ Admin API ── AI Control Center
```

## Что меняется в клиенте (минимально)
Метки «ИИ» уже есть везде. Возможные дополнения: событийный/региональный каналы чата (D-11), союзы гильдий (D-12),
настройка «не получать личные сообщения от ИИ». Все — в одном финальном APK.

## Контрольный список следующего этапа (Фаза 3: этапы 2, 4, 7, 14)
1. Перечитать мастер-ТЗ: этапы 2, 4, 7, 14; разделы 6, 7, 8; решения D-02, D-06, D-09.
2. Личности: архетипы как данные (`ai_archetypes`), черты, амбиции, привычки; эволюция от побед/поражений/общения.
3. Слои силы (новичок, обычный, опытный, ветеран, элита) и темпы развития; переход прогресса на правила игры (D-02).
4. Речь: настройки «интеллекта», длины, частоты, глубины контекста; адаптер локальной модели (выкл. по умолчанию, D-09).
5. Память: версии, архив, биография, контрольные точки; убрать удаление журнала через 7 дней (D-06).
6. Тесты: эволюция личности, отсутствие потери истории, работа без локальной модели, нагрузка.
