# URALIA Living World AI — ДОРОЖНАЯ КАРТА

> Этапы мастер-ТЗ, сгруппированные по фазам, с зависимостями. Каждый этап: MASTER SPEC CHECKPOINT → реализация →
> тесты → документы → проверка соответствия. APK — один раз в конце (фаза 8).

## Зависимости модулей
```
AI Director ─┬─ Activity Scheduler ── Population Manager
             ├─ Task/Event queues ─┬─ Behavior Engine ── Personality Engine
             │                     ├─ Progression Engine ┐
             │                     ├─ PvP Engine         ├─ игровые сервисы (бой, кампания, призыв, арена, гильдии)
             │                     ├─ Economy Engine     ┘
             │                     ├─ Social Engine ── Chat Engine ── Guild Engine
             │                     └─ Event Engine
             ├─ Memory Manager (все модули пишут в память)
             ├─ Analytics
             └─ Admin API ── AI Control Center
```

## Что меняется в клиенте (минимально)
Метки «ИИ» уже есть везде. Возможные дополнения: событийный/региональный каналы чата (D-11), союзы гильдий (D-12),
настройка «не получать личные сообщения от ИИ». Все — в одном финальном APK.
