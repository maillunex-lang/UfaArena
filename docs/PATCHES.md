# ZIP-патчи настроек и задания для ИИ

Любую настройку в админке можно менять **вручную** или **патчем**. Патч — это ZIP-архив с файлом `patch.json`
(картинки и 3D-модели лежат в папке `files/`) или просто текст JSON. Патч можно сделать самому или поручить ИИ
(Gemini, Claude, ChatGPT, Grok).

## Как это работает (для владельца)

1. В любом редакторе нажмите **«🤖 ИИ / патч»**: у героя, у списка героев, в кампании (у каждой главы), в редакторе
   карты, в «Интерфейсе», в каждом разделе ИИ-жителей, у переключателей ИИ, у каждого слота «Графики», в «Магазине».
   Можно и сразу: «Редактор игры» → «ZIP-патчи и ИИ».
2. Выберите объект (или «все сразу») и напишите своими словами, что хотите.
3. **«Скопировать задание для ИИ»** — вставьте его в чат с ИИ. Если ИИ умеет принимать файлы, можно ещё приложить
   **«Шаблон ZIP»**: в нём `patch.json` с текущими значениями и `AI_TASK.md` с заданием.
4. ИИ вернёт `uralia_patch.zip` или блок JSON.
5. В разделе «2. Загрузить патч» выберите ZIP или вставьте JSON (можно прямо с ```json … ```) → **«Проверить патч»**.
   Админка прогонит каждое изменение через те же проверки, что и ручные редакторы, и покажет «было → станет». На этом
   шаге ничего не записывается.
6. **«Применить патч»**. Применяется всё или ничего. Если в патче есть графика, отметьте «Сразу опубликовать графику»
   или потом нажмите «Графика» → «Опубликовать».
7. В «Истории патчей» последний патч можно **откатить** и скачать.

То же самое работает в приложении «Уралия Админ» (с версии 1.1 шаблоны сохраняются в «Загрузки»).

## Формат

```json
{
  "format": "uralia-patch/1",
  "title": "Коротко: что делает патч",
  "description": "Подробнее",
  "author": "Gemini / Claude / ChatGPT / Grok",
  "changes": [ {"type": "…", "…": "…"} ]
}
```

- Порядок изменений важен: они применяются по очереди (например, сначала создаётся глава, потом её этапы).
- Неизменённые поля можно не писать: правка героя или этапа **дополняет** текущие значения.
- Ограничения: архив до 60 МБ, до 200 файлов, до 500 изменений. Разрешены файлы json, png, jpg, jpeg, glb, txt, md.
  Пути с `..` запрещены. Ничего исполняемого: никакого кода, скриптов или SQL.
- Удалять героев, главы и этапы патчем нельзя, только скрывать или отключать. Прогресс игроков не теряется.

## Шаблоны по каждой настройке

Полное и актуальное описание полей с допустимыми значениями (фракции, классы, коды врагов, иконки…) админка
вставляет в задание автоматически. Ниже — образцы.

### Герой / враг — `hero`
```json
{"type": "hero", "code": "azamat", "fields": {"base_atk": 150, "base_spd": 95, "lore": "Новая легенда…"}}
{"type": "hero", "code": "new_batyr", "fields": {"name": "Новый батыр", "faction_code": "stone_sky", "class_code": "warrior",
  "rarity": 4, "base_hp": 3200, "base_atk": 260, "base_def": 140, "base_spd": 100, "model": "knight"}}
{"type": "hero", "code": "old_hero", "disabled": true}
```

### Глава кампании — `region`
```json
{"type": "region", "code": "r8_aslykul", "fields": {"name": "Озеро Аслыкуль", "order": 8, "real_place": "Аслыкуль",
  "description": "…"}}
```

### Этап кампании — `node`
```json
{"type": "node", "code": "r8_1", "fields": {"name": "Берег тумана", "region_code": "r8_aslykul", "order": 1,
  "territory": "nature", "enemies": [{"hero_code": "e_warrior", "level": 42, "slot": 0}],
  "rewards": {"gold": 900}, "first_clear_rewards": {"crystals": 30},
  "story": [{"speaker": "narrator", "text": "Над водой поднимается туман…"}]}}
```

### Порядок этапов — `node_order`
```json
{"type": "node_order", "region_code": "r1_shikhany", "codes": ["r1_1", "r1_3", "r1_2"]}
```

### Карты — `map`
```json
{"type": "map", "world": {"r1_shikhany": [0.45, 0.5]}, "nodes": {"r1_1": [2, -3]}}
```

### Интерфейс: кнопки и экраны — `ui_layout`
```json
{"type": "ui_layout", "merge": {"home": {"left": [{"id": "arena", "label": "Поединки", "icon": "arena"}]}}}
{"type": "ui_layout", "layout": {"nav": […], "home": {…}, "more": {…}}}
```

### Настройки ИИ-жителей — `ai_settings`
```json
{"type": "ai_settings", "section": "speech", "values": {"chat_min_gap_s": 15}}
{"type": "ai_settings", "section": "director", "values": {"mode": "normal", "active_max": 80}}
```
Разделы: `director`, `speech`, `memory`, `tiers`, `channels`, `guilds`, `outreach`, `play`, `pvp`, `events`. Ключи
языковых моделей патчем не задаются.

### Переключатели ИИ — `ai_switches`
```json
{"type": "ai_switches", "values": {"arena": false, "chat": true}}
```

### Товар магазина — `shop_product`
```json
{"type": "shop_product", "sku": "crystals_small", "fields": {"discount_pct": 20, "active": true}, "reason": "Акция"}
```
Цена `price_rub` указывается в копейках. Новые товары патчем не создаются, реальные платежи этим не включаются.

### Графика: картинка или 3D-модель — `art`
```json
{"type": "art", "path": "icons/gold.png", "file": "files/gold.png"}
{"type": "art", "path": "models/heroes/azamat.glb", "file": "files/azamat.glb", "scale": 1.1,
 "anims": {"idle": "Idle", "attack": "Attack_1", "hit": "Hit", "death": "Death", "walk": "Walk"}}
```
Сам файл кладётся в архив. Размер в пикселях и требование прозрачного фона у каждого слота свои. Задание для слота
содержит готовый промпт для генерации картинки.

## Для разработчика

- Сервер: `server/app/game_editor/patches.py`. Типы — классы `T` в словаре `TYPES`: `state`, `apply` (вызывает функции
  ручных редакторов), `keys` (что снимать для отката), `export` (текущее состояние как патч), `doc` (правила для ИИ).
  Новая настройка = новый класс плюс регистрация в `TYPES`.
- API: `/admin/api/game/patches/types | targets | task | template | check | apply | rollback | {id}/file`, история —
  `GET /admin/api/game/patches`.
- Атомарность: одна транзакция без точек сохранения (SQLite фиксирует при RELEASE). «Проверить» откатывает всё и
  заново проигрывает удачные изменения, чтобы показать вердикт по каждому. Файлы графики пишутся только после того,
  как прошла часть с базой данных.
- Тесты: `server/tests/test_patches.py`.
