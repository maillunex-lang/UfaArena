# Уралия Админ — админ-панель как приложение Android

Полноэкранная обёртка (WebView) над страницей `/admin` игрового сервера. Внутри нет секретов: токен администратора
вводится в самой панели; галочка «Запомнить вход на этом устройстве» хранит его только на этом телефоне
(кнопка «Выйти» стирает).

- Скачать: https://github.com/maillunex-lang/UfaArena/raw/apk/uralia-admin.apk (пакет `ru.uralia.admin`, отдельно от игры).
- Адрес по умолчанию: `http://144.31.254.99:8000/admin`. Кнопка «Назад» на первой странице → меню: обновить,
  сменить адрес сервера, выйти. При ошибке загрузки адрес предлагается сменить автоматически.
- Во весь экран (системные панели скрыты, появляются свайпом), экран не гаснет, работает загрузка файлов
  (графика, 3D-модели, APK), масштаб пальцами.

Сборка без Gradle: `SDK=<android-sdk> KEYSTORE=<debug.keystore> ./build.sh ../build/uralia-admin.apk`
(aapt2 + javac + d8 + zipalign + apksigner). Версия — `android:versionCode/versionName` в `AndroidManifest.xml`.
